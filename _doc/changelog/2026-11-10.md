# 2026-11-10 衣改 FitNote 完整本地应用

## 功能与体验

从平台初始模板实现完整的本地试衣修改工具：工作台、可搜索筛选的列表、创建与复制归档、五类原创正反面 SVG、归一化标注、明细编辑与排序、状态、撤销重做、照片非破坏性圈选、版本定稿和对比追踪、离线中文 A4 PDF、工作室设置、全量备份恢复。

用户确认视觉为暖米白、墨绿、少量黄铜色。用户试用反馈流程复杂后，简化创建表单和修改项默认字段，补充信息与工艺状态按需展开；移除可撤销删除操作的额外确认，重要定稿/恢复用应用内确认层兼容 WebView。

## 关键实现

- React / TypeScript / Vite + TopArrow Node 内置 SQLite，独立服务构建后无需 node_modules。
- TOPARROW_DATA_DIR 是运行时唯一写入根目录；端口只绑定环境变量指定的 127.0.0.1。
- SQLite 迁移、事务、revision 乐观锁、不可写定稿和完整版本快照。
- 坐标经 SVG 逆变换归一化，窗口缩放不改变原图位置。
- PDF 完整嵌入本地 Noto Sans SC TTF，避免子集嵌入漏字；图纸和照片高分辨率合成。
- 修复 PDF Worker 的 .mjs MIME 问题；使用 /pdf-worker.js，服务同时正确支持 .mjs。
- SQLite backup API、照片附件、SHA-256 清单、恢复前安全备份及事务恢复。
- 发布包采用白名单，排除用户数据、源码文档、开发依赖、运行时、Git 和原生插件。

专属图标使用内置 image_gen 生成，最终复制至根目录 icon.png 与 public/icon.png，缩至 384×384 / 159146 字节。提示词：premium tailoring fitting annotation app icon; simplified ivory jacket lapel, brass shoulder fitting pin, tiny dashed seam, forest green background; generous margins; no text or mockup。原始图保留在生成工具默认目录，业务资源只引用项目内文件。

## 归档管理与中英文切换

用户反馈归档入口不明显，并要求中英切换。本次新增侧栏独立“归档管理”及归档数量，支持关键词、服装与状态筛选、打开查看和可见文字恢复按钮；从归档单返回时保留归档上下文。归档保持全部版本及附件，恢复只改变归档标记。

界面固定文字抽离到 src/locales 中文和英文 JSON，覆盖页面、字段、空状态、确认层、操作提示、标准服装部位和动作、版本比较及 PDF 标签。语言可从右上角或设置页即时切换，写入 SQLite settings.locale；重开、备份和恢复均保留。切换不刷新页面、不改写客户资料或正在编辑的业务数据。英文选项沿用原有数据库规范值，避免破坏状态筛选和历史比较。

英文 PDF 支持标准标签、英文单词换行、ASCII 标准字体与按实际高度计算确认栏。中文客户及自定义说明保留原文。

验证：TypeScript、构建、9 项自动测试通过；实际界面检查中英切换、未提交表单保留、英文标记保存、归档打开与返回、恢复至普通列表、重开语言记忆和设置入口。英文 PDF 内嵌预览、Poppler 渲染与文本检查通过，中文客户及 Left shoulder / Take in 1 cm 完整、排版无重叠。更新了交付构建和白名单发布包。

## 本机备份管理与归档删除

- 增加手动本机备份及按时间倒序的备份列表，标明手动、删除前和恢复前类型。列表可直接恢复到任意保存时间点，不下载迁移包，不选择外部文件导入。
- 每次恢复前先保存当前完整状态，恢复前状态也留在列表供切回。恢复覆盖整个工作空间及设置，不做单条合并。
- 归档管理增加删除入口和包含单号的确认提示。先完整备份，再事务删除单据所有版本；只有未被其他单据使用的照片会清理。备份失败或记录已变化时拒绝删除。
- 增加本机备份列表及按名称恢复接口，移除旧备份文件下载和二进制导入接口。生成与恢复容量限制一致，迟到的写请求在备份/恢复期间也被阻止。
- 备份入口同时可从归档页直达，当前数据目录收进可展开信息，中英文同步。

验证：类型检查、生产构建及 10 项自动测试通过；覆盖旧/新时间点来回恢复、删除前安全备份、删除专属照片而保留共享照片、恢复照片、缺失附件导致备份失败时保留单据、非法备份名及损坏数据拒绝。界面实际检查手动备份入列、按日期显示、删除与恢复确认及取消；不触发备份下载或文件选择。未操作真实用户单据。
